# Skew-cosh-Laplace-Approximation
- `Skewed Bayesian Logistic Regression.R.` `R` script reproducing the results obtained in Section 6.2
- `Simpler Skewed Bayesian Logistic Regression.R.` `R` script reproducing the results obtained in Appendix F.2
- `skew_cosh.R.` `R` script containing the functions necessary to construct the sampler proposed in Appendix F.1
- `Post-logistic.stan.` `Stan` code for both the regressions
- `Functions.R.` `R` script containing a set of useful functions
  
All the analysis were performed on a **HP ZBook Fury G1i** using **R 4.6.1**.
